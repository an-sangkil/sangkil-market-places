# 풀스택 실행 계획 스킬

## 목적

요구사항 문서를 프론트엔드(Next.js) + 백엔드(FastAPI) 실행 계획으로 변환한다.

## 입력 수집

- PRD / 기능·비기능 요구사항
- UI 목업 / 이벤트 흐름 (Figma URL)
- 외부 API 계약 / 타임라인 제약

## 요구사항 분석 체크리스트

1. 문제를 한 문장으로 설명할 수 있는가?
2. 사용자 액터와 주요 시나리오가 명확한가?
3. 입력/출력/예외가 정의되었는가?
4. 외부 API/시스템 의존성이 식별되었는가?

## 실행 단계

1. **목표 재정의** — 1문단
2. **요구사항 분해** — 사용자 시나리오별
3. **기술 번역** — 프론트엔드 + 백엔드로 분리

### 프론트엔드 관점 (Next.js)

| 측면 | 정의 항목 |
|------|----------|
| 페이지 | App Router 경로, 레이아웃, 메타데이터 |
| 컴포넌트 | UI 컴포넌트, props, 상태 관리 |
| API 연동 | React Query 쿼리/뮤테이션, Axios 호출 |
| 스타일 | Tailwind 클래스, 반응형 설계 |
| 타입 | TypeScript 인터페이스, 타입 정의 |

### 백엔드 관점 (FastAPI)

| 측면 | 정의 항목 |
|------|----------|
| API | 엔드포인트, 요청/응답 스키마, 에러 코드 |
| DB | SQLAlchemy 모델, 쿼리, 마이그레이션 |
| 서비스 | 비즈니스 로직, LLM 연동, 데이터 가공 |
| 설정 | 환경 변수, pydantic-settings |

4. **태스크 분해** (Epic → Story → Task)
5. **완성 계획** — 일정/리스크/검증

## 품질 게이트

- 모든 요구사항이 최소 1개 태스크에 매핑
- 프론트엔드/백엔드 관점 모두 완료
- 우선순위와 일정이 충돌하지 않음
- 테스트 전략이 성공 기준을 검증
