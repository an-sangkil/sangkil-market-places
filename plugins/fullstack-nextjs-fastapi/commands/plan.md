description: 기술 플랜 작성
---

`docs/design/{feature-name}/requirements.md`를 기반으로 기술 플랜을 작성합니다.

대상:
$ARGUMENTS

1. requirements.md를 읽습니다
2. 기존 코드 패턴을 분석합니다
3. 프론트엔드(Next.js) + 백엔드(FastAPI) 설계 포인트를 정리합니다
4. 태스크를 분해합니다 (Epic → Story → Task)
5. plan.md를 저장합니다

산출물: `docs/design/{feature-name}/plan.md`
